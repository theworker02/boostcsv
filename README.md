# boostcsv

Boost digests and csv fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/boostcsv/

## Install / run

```bash
git clone https://github.com/theworker02/boostcsv.git
cd boostcsv
node src/cli.js
node --test
```
